# Nancy Ongolo — Landing page

Landing page premium pour Nancy Ongolo, business coach en cosmétique capillaire.

Stack : Next.js (App Router) · React · TypeScript · Tailwind CSS · déploiement Vercel.

## Développement

```bash
npm install
npm run dev
```

## À personnaliser

- `src/lib/site.ts` : numéro WhatsApp, e-mail, Instagram, URL du site.
- `src/components/sections/Testimonials.tsx` : témoignages d'exemple à remplacer par de vrais retours clientes.
- `src/components/BookingModal.tsx` : questions du formulaire « Réserver un appel » (envoi pré-rempli sur WhatsApp).
